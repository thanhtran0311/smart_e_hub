# Báo cáo cuối kỳ (nguồn Markdown)

Bài nộp cuối kỳ phải là **01 file PDF** nộp qua LMS. Theo đề, nội dung bắt buộc gồm:

1. **Toàn bộ nội dung Submission #1**: bối cảnh dự án, các bên liên quan, yêu cầu chức năng (use-case diagram + đặc tả), yêu cầu phi chức năng.
2. **Toàn bộ nội dung Submission #2**: mockup UI, sequence diagram, activity diagram (state-chart nếu có).
3. **Toàn bộ nội dung Submission #3**: deployment view, development/implementation view, class diagram và mô tả mọi phương thức.
4. **Demo bằng chuỗi màn hình** (xem [kịch bản demo](demo-script.md) và [ảnh chụp](screenshots/)).
5. **Khai báo sử dụng Generative AI**: công cụ, phạm vi, mức đóng góp (xem [khai báo sử dụng AI](../ai-usage.md)).

Ngoài ra cần **slide thuyết trình** ([thư mục slide](slides/)), gồm bài học kinh nghiệm của nhóm.
